# Margin

A local-first visual workspace for annotating PDFs, drawing freely, and taking notes in the margins.

Import a PDF or create a blank canvas, then draw, highlight, add movable text notes, insert images, and continue later from your local SQLite history.

## Features

- Page-by-page PDF annotation
- Freehand pen, highlighter, and eraser
- Movable text notes and side margins
- Multi-page blank canvases with image import
- Local SQLite persistence and project history

## Development

```bash
npm install
npm run dev
```
